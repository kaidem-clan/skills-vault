# AGENTS.md — правила для агентов в этом репозитории

Этот репозиторий — хранилище скиллов. Следуйте правилам при любом изменении.

## Добавление нового скилла

При добавлении нового скилла:

1. Создайте папку `<skill-name>/` в корне репозитория с файлом `SKILL.md` внутри.
2. **Автоматически** добавьте строку в таблицу «Навигация по скиллам»
   в `README.md`:

   ```markdown
   | `skill-name` | Краткое описание в одну строку: что делает и когда применять. |
   ```

3. Если скилл использует дополнительные файлы (скрипты, шаблоны, референсы) —
   все они должны лежать внутри папки скилла.

README.md — это навигация. Скилл, которого нет в README, считается
не добавленным. Не оставляйте таблицу и фактическое содержимое репозитория
в рассинхроне.

## Изменение / удаление скилла

- При переименовании или удалении скилла обновите соответствующую строку
  в таблице `README.md`.
- При изменении назначения скилла обновите его описание в `README.md`.
